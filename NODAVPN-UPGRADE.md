# Апгрейд NodaVPN-бота: 3.41.0 → 3.67.0

Ветка `nodavpn/upgrade-3.67`. `master` не тронут — если что-то пойдёт не так,
просто удали ветку.

## Что сделано

Репозиторий был squash-импортом апстрима без общей истории, поэтому `git merge`
не работал в принципе. История восстановлена: ветка начинается от чистого тега
`v3.41.0`, поверх лежит один коммит со всеми правками NodaVPN, дальше — 25
последовательных мержей апстрима до `v3.67.0`.

Теперь это настоящий форк. Следующий апгрейд — просто `git merge v3.68.0`.

## Ради чего всё затевалось

`MONTH_ROLLING` приехал (`app/external/remnawave_api.py`,
`app/services/subscription_service.py`). Панель его поддерживает с Remnawave
2.7.0, у тебя она новее.

**В `.env` поменяй одну строку:**

```diff
-DEFAULT_TRAFFIC_RESET_STRATEGY=ANNIVERSARY
+DEFAULT_TRAFFIC_RESET_STRATEGY=MONTH_ROLLING
```

`ANNIVERSARY` не существует в коде — значение молча падало в `NO_RESET`, из-за
чего у всех 226 активных подписок трафик не сбрасывался ни разу.

После старта прогони в админке синхронизацию в панель, чтобы существующие
пользователи переехали со `NO_RESET`.

## Что сохранено из твоего

Проверено автоматической сверкой отпечатка UI (1966 кнопок до / 2127 после):

- **раскладка меню — идентична**, ни один эмодзи кнопок не потерян;
- `style=` у кнопок (твои цвета) в `app/services/menu_layout/service.py` —
  апстрим переименовал соседнюю переменную, свёл к общему знаменателю;
- твой экран реферальных конкурсов вместо апстримовских мини-игр
  (`app/handlers/contests.py` целиком твой, `build_main_menu_contest_block`
  используется в 4 местах главного меню);
- карточка подписки прямо в главном меню (`get_subscription_info_text_for_start`)
  вместо апстримовского `try_answer_rich_main_menu`;
- твой `blackquote`-формат карточки в `app/handlers/subscription/purchase.py`;
- deep links приложения NodaVPN в `app/handlers/start.py` (плюс их перехват
  Keitaro subid — работает и то и другое);
- «Назад» ведёт в главное меню, а не в подменю подписки (6 мест в `links.py`);
- двухрядная раскладка `[Докупить трафик] [Устройства]` на экране подписки;
- локальное время во всех датах (`format_local_datetime`);
- живой трафик из панели в кабинете — перенесён в новый
  `app/cabinet/routes/subscription_modules/status.py`, апстрим распилил монолит;
- твои строки локалей: значения побеждают апстримовские, новые ключи добавлены.

Кнопку «📤 Поделиться» апстрим удалил в 3.42.0 — **вернул**, вместе с текстом
подсказки во всех пяти языках.

## Что изменилось не по твоей воле

- Админский экран лимита устройств: было фиксированное `1 / 2 / 3 / 5 / 10`,
  апстрим генерирует `1..N` циклом по текущему кэпу. Только админка.
- Уведомления об истечении получили плейсхолдер `{tariff_label}` — для
  однотарифных подписок он пустой.
- Приехали новые экраны мульти-подписок (`my_subscriptions.py`). Пока
  мульти-тариф выключен, они не показываются.

## Заодно починены два реальных бага

- `app/handlers/start.py`: локальный `import get_user_by_referral_code` делал имя
  локальным для всей функции, и `/start` с реферальным кодом падал с
  `UnboundLocalError`.
- `app/handlers/simple_subscription.py`: `format_local_datetime` использовался
  без импорта.

## Как разворачивать

**Сначала бэкап БД. Обязательно.** На старте бот сам прогонит alembic, а между
3.41 и 3.67 приехало **58 новых миграций** (0046 → 0103): мульти-подписки,
вложения в тикетах, новые платёжки, юр-согласия. Откатить это будет нечем.

```bash
pg_dump -U postgres -Fc bedolaga > backup-$(date +%F).dump

git fetch origin
git checkout nodavpn/upgrade-3.67

# правки .env
#   DEFAULT_TRAFFIC_RESET_STRATEGY=MONTH_ROLLING
#   при желании — блоки из NODAVPN-UPGRADE.env.example

docker compose up -d --build
docker compose logs -f bot
```

Апстрим добавил 86 новых переменных окружения. У всех есть дефолты в
`app/config.py`, бот стартует без них — полный список с дефолтными значениями
лежит в `NODAVPN-UPGRADE.env.example`, добавляй только то, что включаешь.

## Что проверить руками

Локально запустить не вышло: проект на Python 3.13, а `aiohttp` и
`pydantic-core` нужных версий не собираются под 3.14 без компилятора. Прошло
только статическое: полная компиляция всех файлов, ноль конфликтных маркеров,
pyflakes без новых ошибок относительно апстрима, все локали — валидный JSON.
Так что боевая проверка на тебе:

1. `/start` — карточка подписки в главном меню, порядок и цвет кнопок;
2. `/start` по реферальной ссылке (тот самый починенный баг);
3. экран подписки — два ряда кнопок, «Назад» ведёт в главное меню;
4. deep links из приложения NodaVPN: `buy_traffic_5`, `renew_30`, `devices_3`;
5. экран конкурсов и блок конкурса в главном меню;
6. «📤 Поделиться» на экране приглашения;
7. кабинет: цифры трафика совпадают с панелью;
8. **главное** — купить тестовую подписку и убедиться, что в панели у неё
   `trafficLimitStrategy = MONTH_ROLLING`, а через месяц счётчик обнулился.
